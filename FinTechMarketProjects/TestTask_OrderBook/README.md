## Overview
Naive implementation of the Order Book and its three certain test functions


<a name="Requirements"></a>
## Project requirements
1. Linux (_Tested on Ubuntu 20.04.4 LTS_)
2. C++20
3. Cmake
5. (gcc-11 or clang-14)


<a name="Build"></a>
## How to build project:
- `mkdir build`
- `cd build`
- Setup compilers if required `export CC=gcc-11 CXX=g++-11`  (for example)
- `cmake ..`
- `make all`


<a name="Run"></a>
## Run:
- **Usage**: `./TestTask_OrderBook`
